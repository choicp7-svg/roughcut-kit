# 캡컷 컷편집 · 자막 자동화

윈도우 · 맥 공용. 캡컷 경로와 폰트는 실행하는 PC에서 자동으로 찾는다.

미감이 필요한 편집(B롤, 강조 자막, 색보정)은 사람이 한다. 효과음은 사용자가 원하면 그 사람 습관을 학습해서 넣는다(6단계).
이 스킬은 그 **앞단의 반복 노동**(컷편집·자막 싱크·오타·줄 나누기)만 처리해서 편집자가 바로 미감 작업에 들어가게 한다.

스크립트는 이 SKILL.md와 같은 폴더의 `scripts/`에 있다.
아래에서 `RUN` 은 `python3 "${CLAUDE_SKILL_DIR}/scripts/run.py"` 를 뜻한다.
(윈도우에서 `python3`가 없다고 하면 `python`으로. Cowork에서는 위에 표시된 이 스킬의 Base directory 를 쓴다.)

## 0. 환경 확인 (세션당 1회)

```
RUN check
```

`ok: true` 와 함께 `os`(win/mac) · `mode`(native/cowork) · 캡컷 루트 · 최근 프로젝트 · 이 PC에 설치된 폰트가 나오면 준비 끝.

- **클로드 코드(터미널)에서 실행 중이면** 캡컷 폴더를 알아서 찾는다. (윈도우 `%LOCALAPPDATA%\CapCut`, 맥 `~/Movies/CapCut`)
  못 찾으면 캡컷을 다른 위치에 설치한 것 — 환경변수 `CAPCUT_DRAFT_ROOT` 에 `…/CapCut/User Data/Projects/com.lveditor.draft` 경로를 넣어주면 된다.
- **Cowork(데스크톱 앱)에서 실행 중이면** 파일이 `~/mnt/<폴더명>` 아래에 보인다. 캡컷 폴더가 연결돼 있지 않으면 `device_request_folder_access`로 **캡컷 폴더와 원본 영상 폴더를 한 번에** 요청한다 (윈도우 `~/AppData/Local/CapCut`, 맥 `~/Movies/CapCut`). 원본 영상 폴더를 모르면 프로젝트의 `materials.videos[].path`를 먼저 읽어서 알아낸다. 스크립트는 `device_bash`로 돌린다.
- `python3` 또는 `ffmpeg`가 없다고 나오면 사용자에게 설치를 안내한다 (윈도우: `winget install Python.Python.3.12` / `winget install Gyan.FFmpeg`, 맥: `brew install python ffmpeg`).

## 1. 사용자가 먼저 해야 하는 것

> 캡컷에 원본 영상을 넣고 **[자동 자막]만** 실행 → 저장 → **프로젝트 닫기**

컷은 건드리지 않은 통영상 상태여야 한다. 프로젝트가 캡컷에서 열려 있으면 작업 결과가 덮어써지므로 반드시 닫게 한다.
자막 트랙이 없으면 `analyze`가 실패한다 — 그때는 자동 자막부터 돌리라고 안내한다.

## 2. analyze — 기계가 걷어낼 수 있는 것

```
RUN analyze --project 0904
```

수행 내용:
- 원본 오디오에서 발화 구간 검출(ffmpeg + 에너지 VAD) 후 자막 경계를 실제 발화 시작에 스냅
- **반복 테이크 제거** — 같은 말을 여러 번 한 구간은 **마지막 테이크만** 남긴다 (한 문장이 여러 줄로 쪼개진 테이크도 묶어서 비교)
- 슬레이트·디렉션 제거 ("카메라 롤리", "하나 둘", "한 번 더", "컷 오케이")
- 말하다 만 조각, 필러("어", "음", "으") 제거
- 결과를 `review.json`(스크립트 폴더)에 저장하고 전부 출력

원본 영상을 못 찾으면 `--video /경로/원본.mp4` 로 직접 넘긴다. (4K 원본이어도 오디오만 뽑으므로 몇 초면 끝난다.)
옵션: `--fillers off|safe|hard` (기본 safe) · `--sens` VAD 민감도 · `--max-shift` 리싱크 허용 이동폭

## 3. 문맥 교정 — 이건 Claude가 직접 한다

`analyze` 출력을 **전부 읽고** 오인식을 문맥으로 고친다. 스크립트가 못 하는 부분이고, 이 스킬의 핵심 가치다.
사용자가 대본을 같이 줬으면 **대본을 기준**으로 맞춘다. 대본이 없으면 문맥으로 판단한다.

실제로 자주 나오는 유형:

| 자동자막 | 교정 |
|---|---|
| 완성본을 **단독방** | 완성본을 **단톡방** |
| 올려도 **좋아질로** 올라갑니다 | 올려도 **저화질로** 올라갑니다 |
| 컵 편집 / 퍼 편집 | 컷편집 |
| 모타 수정 | 오타 수정 |
| 리스뿐만 아니라 | 릴스뿐만 아니라 |
| 한두 **10간** | 한두 **시간** |
| 프롬부터 / 프럼프트 | 프롬프트 |
| **제1** 친한 친구 | **제일** 친한 친구 |

원칙:
- **영어 약어·브랜드명은 표기를 통일한다** (티엠아이 → TMI, 클로드코드 → 클로드 코드)
- 맞춤법·띄어쓰기를 정리한다 (뒤쳐지고 → 뒤처지고, 팔로우 500만 → 팔로워 500만)
- 자동자막이 삼킨 조사·주어를 문맥으로 복원한다
- **확신이 없는 고유명사는 고치지 말고 사용자에게 물어본다.** 사람 이름·브랜드명을 추측해서 바꾸면 사고가 난다.
- 시간값(`start`, `end`)은 건드리지 않는다. 텍스트만 고친다.

### 반복 테이크 — 스크립트가 못 잡은 건 Claude가 잡는다

`analyze`가 남긴 목록에 같은 문장이 아직 여러 번 보이면 **마지막 테이크**를 고른다.
단, 마지막 것이 말하다 만 조각("…해줘요" 하고 끊김)이면 그 앞의 완성된 테이크를 쓴다.
자동자막의 시작 시간이 실제 발화보다 늦게 잡혀 있는 경우가 많으니, 테이크의 시작·끝은 `review.json`의 `segs`(발화 구간)를 기준으로 잡는다.

### 줄 나누기 — 의미 단위로 끊는다

발화 구간 하나를 통째로 잡은 뒤 **의미 단위로** 줄을 나누고, 시간은 글자수 비례로 배분한다
(`pipeline.lines_from_groups([(시작, 끝, ["줄1","줄2"]), ...])`).

나쁨: `첫 번째, 뭘 올릴지. 둘째,` / `그걸 어떻게 잘 만들지`
좋음: `첫 번째, 뭘 올릴지` / `둘째, 그걸 어떻게 잘 만들지`

한 줄 10~12자, 쉼표·접속사·절 경계에서 끊는다. 조사나 어절 중간에서 자르지 않는다.

### 조용한 테이크 검증 — 반드시 할 것

리허설로 웅얼거린 구간을 진짜 테이크로 착각하는 사고가 실제로 난다.
`pipeline.loud_fn(wav)`로 모든 줄의 음량을 재고, **중앙값보다 10dB 이상 낮은 줄**은
같은 대사의 다른 테이크(더 큰 소리)로 바꾼다. 대체할 테이크가 없으면 사용자에게 알린다.

교정한 결과를 `final.json`(`[[start, end, "텍스트"], ...]`)으로 저장한다.

## 4. build — 러프컷 + 자막 프로젝트 생성

```
RUN build --project 0904 --cues final.json --segs review.json --preset 치상_그림자 --no-resplit
```

살아남은 자막 구간만 남기고 무음을 잘라낸 뒤, 자막을 얹어서
`<프로젝트명>_러프컷` 프로젝트를 새로 만든다. **원본 프로젝트는 건드리지 않는다.**

| 옵션 | 기본값 | 의미 |
|---|---|---|
| `--preset` | `치상_그림자` | 자막 스타일 (아래 표). 아무 말 없으면 치상 스타일, '심플하게'면 `기본` |
| `--segs` | — | `analyze`가 만든 review.json 경로. **반드시 넘길 것** — 발화 구간을 알아야 목소리를 안 자른다 |
| `--no-resplit` | — | 3단계에서 줄을 이미 손으로 나눴으면 켠다. 안 켜면 스크립트가 10자 리듬으로 다시 나눈다 |
| `--max-gap` | `0.25` | 컷 **사이** 무음 허용치 |
| `--min-pause` | `0.10` | 컷 **안**에 남길 쉼의 최대 길이. **컷 촘촘함을 바꾸는 진짜 손잡이** — 더 촘촘하게는 0.08, 여유 있게는 0.18 |
| `--gap-frames` | `0` | 자막 사이 간격(프레임). **0 = 딱 붙임**이 기본. 자막이 떨어지면 깜빡여 보인다 |
| `--pad-in` / `--pad-out` | `0.06` / `0.10` | 컷 앞뒤 여유 |
| `--no-cut` | — | 컷 없이 자막만 교체 |

build 후에 확인할 것:
- 출력의 `0.2초 초과 구간` 이 0곳인지 (컷 안에 긴 마가 남으면 파형에 평지가 보인다)
- 자막 세그먼트끼리 겹치는 게 없는지 (있으면 앞 자막 끝을 다음 시작으로 맞춘다)

## 5. 사용자에게 보고

- 원본 → 결과 길이, 컷 수, 자막 줄 수
- **반복 테이크를 몇 번째 것으로 채택했는지**
- 교정한 텍스트 목록 (표로)
- **확신 없어서 남겨둔 항목** — 검수 때 볼 것으로 명시
- 컷 호흡이 안 맞으면 `--min-pause` 하나로 조절 가능하다고 안내
- 캡컷을 **다시 열어야** 새 프로젝트가 목록에 보인다고 안내

## 6. 효과음 (선택) — "효과음 넣어줘", "효과음도 같이"

사용자가 **자기 캡컷 프로젝트에서 실제로 써온 효과음**을 학습해서 그 사람 습관대로 얹는다. 이력이 없으면 치상 세트로.
러프컷을 만든 뒤에 한다. 결과 프로젝트가 **캡컷에서 닫혀 있어야** 한다 (열려 있으면 캡컷이 닫을 때 덮어쓴다).
아래에서 `SFX` 는 `python3 "${CLAUDE_SKILL_DIR}/scripts/sfx.py"`.

**⓪ 선택지** — 처음 넣을 때 한 번 묻는다: "효과음은 평소 쓰시던 걸로 학습해서 넣을까요, 제(치상) 세트로 넣을까요?" 초보이거나 답이 없으면 치상 세트. 효과음을 써본 프로젝트가 없으면 묻지 않고 치상 세트로 간다고 알린다.

**① 학습** — `SFX profile` : 이 PC의 프로젝트 60개를 훑어 효과음별 (횟수 / 자막·컷·강조자막 맞춤 % / 볼륨 / 쓴 자막 예시 / 치상세트 역할힌트)와 평소 밀도(N초에 1개)를 출력하고 `sfx_profile.json`에 저장한다.
- 효과음 쓴 프로젝트가 0개면 자동으로 **치상 세트**(`references/sfx_default_set.json`, 15개, 역할·볼륨 정해져 있음)로 바뀐다. 이때 ② 역할 정하기는 이미 돼 있으니 건너뛴다. 밀도는 3초에 1개
- 치상 세트 소리 파일이 이 PC에 없어도 그냥 넣는다. 캡컷은 라이브러리 소리를 `effect_id`로 알아보고 경로를 자기 캐시로 다시 잡는다(파일이 없으면 라이브러리에서 받아온다) — profile 출력의 `받음` 표시가 그것. 혹시 캡컷에서 그 소리만 안 나면 "[오디오 → 효과음] 검색창에 이름 검색해서 아무 프로젝트에 한 번 넣어두세요"라고 안내. 스킬 폴더 `assets/sfx/`에 파일이 있으면 그걸 복사해서 쓴다
- 이력이 있어도 사용자가 치상 세트를 고르면 `SFX profile --set 치상`. 반대로 본인 것만 고집하면 `--set own`

**② 역할 정하기** — 출력 표를 읽고 그 사람의 소리를 아래 역할에 배정한다 (예시 자막이 힌트. 없는 역할은 비워둔다).

| 역할 | 어디에 | 그 사람 소리 고르는 기준 |
|---|---|---|
| 훅 | 0초 | 라이저·셔터·임팩트류. 볼륨 낮게(0.1~0.3), 3초로 자름 |
| 새 문장·새 항목 시작 | 컷 경계와 겹치는 자막 시작 | 클릭·엔터류, 컷맞춤 % 높은 것 |
| 빠른 나열 | 연달아 나오는 항목 자막마다 | 제일 짧은(0.2~0.4초) 클릭. 항목 수만큼 연타 |
| 긍정 결론·포인트 | 문장 끝맺음 자막 ("~됩니다", "~해요") | 차임·반짝·정답류, 볼륨 0.3~0.5 |
| 부정·경고·문제 제기 | "안 됩니다", "깨집니다", "걸리던" 류 | 틱·두둥·어색·오답류 |
| 숫자·통계 | 숫자 든 자막 | 타이핑·글씨·팝류 |
| CTA | 팔로우·댓글·저장 자막 | 알림·정답·타이핑류 |
| 강조 텍스트 등장 | 자막 트랙 밖 큰 글씨가 뜨는 순간 | 강조맞춤 % 높은 것 |

**③ 계획** — `SFX captions --project <프로젝트>_러프컷` 으로 자막 시각과 컷 경계(▌)를 본 뒤, **효과음 시작 = 자막 시작 시각**에 딱 맞춰 `sfx_plan.json` 을 쓴다.
`[[초, "효과음 이름(프로필 표기 그대로)", 볼륨, 최대길이초|null], ...]`
- 개수: 프로필의 평소 밀도(N초에 1개)를 기본으로 하고 **20% 정도 더** 넣는다. 빼는 게 넣는 것보다 쉬워서 사용자가 검수하며 덜어내게 한다. "많이"라고 하면 1.5배, "조금만"이면 절반
- 볼륨은 프로필의 그 소리 볼륨 중앙값을 쓴다. 긴 소리(2초 이상)는 다음 자막 전에 끝나게 최대길이를 준다
- 대본이 있으면 대본 흐름(훅→본론→CTA)으로 역할을 잡는다. 같은 소리를 두 줄 연속 쓰지 않는다 (나열 연타 제외)

**④ 적용** — `SFX apply --project <프로젝트>_러프컷 --plan sfx_plan.json`
`SFX_auto` 트랙을 만들어 얹는다 (겹치면 트랙을 나눔). 다시 실행하면 이전 것을 걷어내고 새로 넣으므로 조정은 계획만 고쳐서 재실행.
출력 끝의 `캐시 정리: Timelines…` 는 정상 — 캡컷이 바깥 파일을 다시 읽게 하는 것이다.

**⑤ 보고** — 몇 개·트랙 몇 개, 역할별로 어디에 뭘 넣었는지 요약, "평소보다 20% 많이 넣었으니 빼면서 맞추라"고 안내, 통째로 빼려면 `SFX_auto` 트랙만 지우면 된다고 안내, 캡컷 다시 열어야 보인다고 안내.

## 자막 스타일

폰트는 **캡컷 기본 폰트**를 쓴다. 사용자 PC에 특정 폰트가 있는지 알 수 없으니, 따로 요청이 없으면 폰트를 지정하지 않는다.
사용자가 스타일을 말하지 않았으면 **치상 스타일(`치상_그림자`)로 넣는다** — 받는 사람 대부분이 초보라 "알아서 괜찮게"가 기본값이다.
처음 쓰는 사용자에게는 한 번만 선택지를 준다: "자막은 치상 스타일로 갈까요, 평소 쓰시던 프로젝트 스타일을 등록할까요?" (답 없으면 치상 스타일)

| 프리셋 | 언제 | 모양 |
|---|---|---|
| `치상_그림자` | **기본값**. "치상 스타일로", "알아서", "추천" | 외곽선 없이 은은한 검정 그림자, 자간 -0.05, 1.165배. 릴스 본문 자막 |
| `치상_검정박스` | 배경이 밝거나 글자가 안 읽힐 때 | 검정 박스 안에 흰 글씨, 하단 |
| `치상_외곽선` | 배경이 복잡할 때 | 굵은 검정 외곽선 + 그림자, 하단, 1.16배 |
| `기본` | "심플하게", "기본으로" | 흰 글씨 + 얇은 검정 외곽선, 중하단 |

치상 스타일 세 개는 아워프로젝트 릴스에서 실제로 쓰는 것이고, 폰트만 캡컷 기본으로 바꿔둔 것이다.

**사용자가 자기 스타일을 쓰고 싶어 할 때** — 자막 스타일을 손으로 잡아둔 캡컷 프로젝트 이름을 받으면
그 프로젝트의 자막 material에서 `font_title` `font_path` `font_size` `text_color` `border_color/width` `has_shadow` `shadow_alpha`
`background_color/style/alpha` `letter_spacing` `line_spacing` 과 세그먼트의 `clip.transform.y` `clip.scale` 을 그대로 옮겨
`capcut_kit.PRESETS` 에 항목을 추가한다 (font_path 가 SystemFont 이면 `font="캡컷 기본"`, 아니면 `font=font_title`).
적용 후 원본 material 과 필드를 대조해 검증할 것.

**폰트를 따로 지정했을 때** — 그 PC의 기존 캡컷 프로젝트를 스캔해 실제 경로를 찾는다 (`env.resolve_font`).
설치돼 있지 않으면 캡컷 기본 폰트로 대체하고 build 출력에 `이 PC에 없는 폰트라 대체함` 이 찍힌다. **무엇이 빠졌는지 사용자에게 반드시 알린다.**
근거 수치는 `references/style-profile.md` 참고.

## 하지 말 것

- 캡컷에서 **열려 있는 프로젝트**의 파일을 쓰지 말 것 (덮어써짐)
- 원본 프로젝트를 수정하지 말 것 — 항상 새 프로젝트를 만든다
- 프로젝트 폴더를 통째로 복사하지 말 것 — 캐시까지 딸려와 수 GB가 된다. `build`가 복사하는 작은 JSON들만으로 충분하다
- 확신 없는 고유명사를 임의로 교정하지 말 것
- **자막 시간만 보고 컷을 만들지 말 것** — 자막이 음성보다 늦게 시작하는 경우가 흔해서 목소리 앞부분이 잘린다. 반드시 `--segs`로 발화 구간을 넘긴다
- **자막 사이를 벌리지 말 것** — 떨어지면 화면에서 깜빡인다
